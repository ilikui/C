# C 语言学习与实践

本仓库用于系统学习 C 语言，包含基础语法练习、C Primer 示例、指针与数组练习，以及算法/数据结构相关代码。建议把它当作一个持续维护的学习实验室：先理解，再手写，最后通过测试和复盘巩固。

## 从哪里开始

- **学习路线：** [12 周 C 语言学习计划](./STUDY_PLAN.md)
- **基础语法：** 从 `Src/CPrimer/` 中按章节学习示例
- **专项练习：** 查看 `Src/Exercise/`
- **算法与数据结构：** 查看 `Src/algo/`

> 仓库目录会随学习进展变化；如果某个路径在当前版本中不存在，请以实际目录为准。

## 推荐学习顺序

1. 环境与编译流程、基本类型、输入输出
2. 分支、循环、数组、字符串
3. 函数、作用域、存储期
4. 指针、数组与指针、字符串内存模型
5. 结构体、枚举、位运算、预处理器
6. 动态内存、文件 I/O、模块化编译
7. 数据结构、调试、测试与综合项目
8. 面向嵌入式的定宽整数、volatile、寄存器位操作和状态机

## 编译与练习建议

使用 GCC 或 Clang 时，可从以下命令开始：

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o main
./main
```

Windows 环境可使用 MinGW-w64/Clang，或在 WSL 中使用 GCC。编译时出现警告应先理解原因，不要简单地关闭警告。

建议每个练习都检查：
- 正常输入、边界输入和错误输入
- 数组下标是否越界、字符串是否正确以 `\0` 结尾
- 指针是否初始化、生命周期是否有效
- 动态内存是否检查分配结果并恰当释放
- 文件操作是否检查返回值

## 学习记录

每完成一个主题，记录：核心概念、最小示例、常见错误、边界测试、自己的解释。完成一周后，把不熟悉的内容重新实现一次，而不是只阅读代码。
