## C语言初级教程


```mermaid
mindmap
  root((C语言知识体系))
    基础语法
      数据类型
        基本: char / int / float / double
        修饰符: short / long / signed / unsigned
      变量与常量
        字面量
        const 常量
        #define 宏常量
      运算符
        算术 / 关系 / 逻辑
        位运算: AND / OR / XOR / 移位
        赋值与三目
    控制流
      分支结构
        if-else 语句
        switch-case 语句
      循环结构
        while 循环
        do-while 循环
        for 循环
        break / continue
    核心基石
      函数
        参数传递: 值传递 / 指针传递
        作用域: 局部 / 全局
        生命周期: static / auto
        递归调用
      数组
        一维数组
        二维数组
        字符串: char 数组与表尾 '\0'
    高级进阶
      指针 (核心中的核心)
        一级与多级指针
        指针算术运算
        数组指针与指针数组
        函数指针与回调函数
      内存管理
        栈内存: 局部变量自动分配
        堆内存: malloc / calloc / realloc / free
      用户自定义类型
        结构体: struct
        共用体: union
        枚举: enum
        位域
    工程与底层
      预处理指令
        文件包含: #include
        条件编译: #ifdef / #ifndef
        宏定义与带参宏
      文件操作
        文本文件读取与写入
        二进制文件操作
        文件指针: FILE* / fopen / fclose


```
