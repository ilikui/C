# 30. 嵌入式 C 综合项目：传感器采集与数据处理

## 项目目标
搭建一个可在主机上模拟、也能移植到 MCU 的小型传感器数据处理模块。项目串联接口设计、驱动抽象、数值安全、状态机、错误处理和单元测试。

## 2. 定义数据契约
~~~c
#ifndef SAMPLE_SERVICE_H
#define SAMPLE_SERVICE_H

#include <stdbool.h>
#include <stdint.h>

typedef enum {
    SAMPLE_OK = 0,
    SAMPLE_ERR_ARGUMENT,
    SAMPLE_ERR_HARDWARE,
    SAMPLE_ERR_RANGE
} sample_status_t;

typedef struct {
    uint16_t raw;
    int32_t milli_units;
    bool valid;
} sample_t;

/* 成功返回 SAMPLE_OK；失败时调用方不得使用旧的输出内容。 */
sample_status_t sample_service_read(sample_t *out);

#endif
~~~

milli_units 表示千分之一单位，但真实项目必须把单位写清楚（例如 m°C、mV 或其他量纲），并根据传感器数据手册确定换算公式和允许范围。

## 3. 处理链路
~~~mermaid
sequenceDiagram
    participant App as 应用状态机
    participant Svc as 采样服务
    participant Port as 硬件适配层
    participant Conv as 数值换算
    participant F as 滤波器
    App->>Svc: 请求一次采样
    Svc->>Port: 读取原始 ADC 值
    Port-->>Svc: raw 或硬件错误
    Svc->>Conv: 校验并换算 raw
    Conv-->>Svc: 定标值或范围错误
    Svc->>F: 输入有效样本
    F-->>Svc: 滤波结果
    Svc-->>App: 样本状态与结果
~~~

## 4. 必须实现的工程规则
- 硬件访问只能出现在 port 层，业务层不得直接读寄存器。
- 任何输出参数都要定义成功和失败时的内容语义。
- 先检查 ADC 原始范围，再执行换算；中间乘法需进行范围分析。
- 滤波器应明确初始化、窗口大小、启动阶段和异常样本策略。
- 连续采样失败应有计数、超时或降级策略，避免无限重试。
- 若由 ISR 写入样本、主循环读取，必须采用目标平台认可的同步方案；volatile 本身不能解决数据竞争或保证复合操作原子性。
- 主机测试使用 fake port；目标板测试验证真实时序、外设配置和中断行为。

## 5. 里程碑
1. **M1：** 编写接口头文件和 fake port，能注入成功与失败结果。
2. **M2：** 完成原始值到物理量的换算，覆盖边界和非法输入。
3. **M3：** 完成滤波器并测试启动阶段、正常数据和异常数据。
4. **M4：** 加入非阻塞采样状态机、超时和错误计数。
5. **M5：** 添加构建命令、测试说明、架构图和已知限制。
