# C 语言细致小节学习手册

本目录按“概念拆解 → Mermaid 关系图 → 代码示例 → 易错点 → 练习与验收”逐节建设。内容以 C11 为基线，尽量与仓库已有章节和示例互相补充，而不是替代原有资料。

## 学习路径

```mermaid
flowchart TD
    A["环境与编译"] --> B["基本数据类型"]
    B --> C["变量、常量与作用域"]
    C --> D["运算符与表达式"]
    D --> E["分支与循环"]
    E --> F["函数与参数传递"]
    F --> G["数组与字符串"]
    G --> H["指针与内存"]
    H --> I["结构体与自定义类型"]
    I --> J["预处理、编译链接与模块化"]
    J --> K["文件 I/O 与错误处理"]
    K --> L["数据结构与嵌入式实践"]
```

## 每节的完成标准

```mermaid
flowchart LR
    A["阅读概念"] --> B["画出关系"]
    B --> C["手写最小示例"]
    C --> D["编译并运行"]
    D --> E{"覆盖边界了吗？"}
    E -- "没有" --> C
    E -- "覆盖了" --> F["完成练习"]
    F --> G["写总结卡片"]
```

- 不只记语法：解释“为什么这样写”和“什么时候会出错”。
- 代码示例使用明确的类型、边界检查和错误处理。
- 编译建议：`gcc -std=c11 -Wall -Wextra -Wpedantic -Wconversion -Wshadow file.c -o app`。警告选项可按项目逐步启用。
- 每次练习至少测试一个正常输入、一个边界输入和一个非法输入。
- 本目录将逐节扩充；原有文档和代码继续保留。
