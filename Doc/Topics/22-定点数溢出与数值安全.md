# 22. 定点数、溢出与数值安全

## 学习目标
- 理解整数运算的范围限制与有符号溢出风险。
- 掌握常见定点数 Q 格式的缩放思路。
- 在传感器换算、滤波和控制算法中明确舍入、饱和与单位。

## 1. 定点数的基本思路
若约定实际值 = 存储整数 / 1000，那么整数 12345 表示 12.345。缩放比例必须由接口约定，不能只靠变量名猜测。

~~~c
#include <stdbool.h>
#include <stdint.h>
#include <limits.h>

/* 将整数毫单位转换为整数单位，采用向最近整数舍入。 */
static bool milli_to_integer(int32_t milli, int32_t *out)
{
    int64_t wide;

    if (out == 0) {
        return false;
    }

    wide = milli;
    if (wide >= 0) {
        wide = (wide + 500) / 1000;
    } else {
        wide = (wide - 500) / 1000;
    }

    if (wide > INT32_MAX || wide < INT32_MIN) {
        return false;
    }

    *out = (int32_t)wide;
    return true;
}
~~~

这个示例演示先扩大中间类型、再做范围检查的模式。真实算法需要明确采用四舍五入、向零截断还是其他舍入规则。若乘法可能超出 int64_t，仍须在乘法前检查边界。

## 2. 为什么不能忽略中间结果
即使最终结果理论上在目标类型范围内，中间乘法也可能先溢出。例如 a * b / scale 应先评估 a * b 的范围，而不是只看除法后的预期结果。对于有符号整数，超出可表示范围是未定义行为；不能依赖回绕。

## 3. 饱和转换示意
~~~c
#include <stdint.h>
#include <limits.h>

static int16_t saturate_i32_to_i16(int32_t value)
{
    if (value > INT16_MAX) {
        return INT16_MAX;
    }
    if (value < INT16_MIN) {
        return INT16_MIN;
    }
    return (int16_t)value;
}
~~~

饱和策略适合某些信号处理场景，但不是所有业务都应静默饱和。安全关键场景可能需要返回错误并记录故障。

## 工程检查表
- 每个数值都注明单位和缩放比例。
- 明确输入范围、输出范围、中间计算类型和舍入规则。
- 乘法前分析溢出；除法前检查除数是否为零。
- 对浮点转整数检查范围，避免越界转换。
- 对传感器异常值定义拒绝、钳位或故障策略。

## 练习与验收
1. 为 ADC 原始值到物理量的线性换算写出单位和范围推导。
2. 实现带上下限检查的整数乘法缩放函数。
3. 测试最小值、最大值、零、负值和接近溢出的输入。
4. 解释截断、四舍五入和饱和之间的区别。

**验收标准：** 数值路径有单位和范围分析；不存在未经评估的有符号溢出；舍入和异常策略明确。
