# 19. 环形缓冲区与中断/主循环协作

## 学习目标

- 理解环形缓冲区的读写索引、满与空的判定。
- 实现可测试的字节队列。
- 明确普通队列、单生产者单消费者（SPSC）队列与并发同步的区别。

## 工作机制

~~~mermaid
flowchart LR
    A["生产者：ISR / DMA 回调"] --> B["写入 data[head]"]
    B --> C["推进 head"]
    C --> D{"队列已满？"}
    D -- "是" --> E["拒绝新数据 / 计数丢弃"]
    D -- "否" --> F["消费者读取 data[tail]"]
    F --> G["推进 tail"]
~~~

## 1. 先实现无并发版本

以下实现采用“空一个槽”的方式区分满和空，实际容量为数组长度减一。该版本适用于由单一执行上下文调用的普通队列；它本身**不是** ISR/主循环并发安全实现。

~~~c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

#define RING_STORAGE_SIZE 64U

typedef struct {
    uint8_t data[RING_STORAGE_SIZE];
    size_t head;
    size_t tail;
} ring_t;

static void ring_init(ring_t *ring)
{
    if (ring != NULL) {
        ring->head = 0U;
        ring->tail = 0U;
    }
}

static bool ring_is_empty(const ring_t *ring)
{
    return ring == NULL || ring->head == ring->tail;
}

static bool ring_is_full(const ring_t *ring)
{
    if (ring == NULL) {
        return false;
    }
    return ((ring->head + 1U) % RING_STORAGE_SIZE) == ring->tail;
}

static bool ring_push(ring_t *ring, uint8_t value)
{
    size_t next;

    if (ring == NULL) {
        return false;
    }

    next = (ring->head + 1U) % RING_STORAGE_SIZE;
    if (next == ring->tail) {
        return false;
    }

    ring->data[ring->head] = value;
    ring->head = next;
    return true;
}

static bool ring_pop(ring_t *ring, uint8_t *value)
{
    if (ring == NULL || value == NULL || ring->head == ring->tail) {
        return false;
    }

    *value = ring->data[ring->tail];
    ring->tail = (ring->tail + 1U) % RING_STORAGE_SIZE;
    return true;
}
~~~

注意：在启用严格编译警告的单独示例中，未被调用的 static 函数可能触发未使用警告；实际工程应在模块接口中使用这些函数或在测试中调用它们。

## 2. ISR 与主循环并发需要额外设计

若 ISR 是唯一生产者、主循环是唯一消费者，仍然需要平台级同步契约。重点核查：

- 索引类型的读写是否自然对齐、是否原子；
- 编译器如何处理 ISR 与普通代码之间共享对象；
- 数据写入与索引发布的可见顺序；
- 是否需要平台原子、内存屏障或临界区；
- 是否存在第二个生产者或第二个消费者；
- 缓冲区满时采用丢新数据、覆盖旧数据还是触发错误。

仅把 head 和 tail 声明为 volatile 并不能普遍解决数据竞争、原子性或顺序问题。C11 原子操作是否适合中断上下文也必须由目标平台验证。

## 3. 测试矩阵

| 场景 | 预期结果 |
|---|---|
| 空队列读取 | 返回失败，不改写输出值 |
| 插入一个字节再读取 | 读回相同字节 |
| 插入到满 | 下一次插入失败 |
| 读出部分数据再插入 | 索引正确回绕 |
| 输入/输出指针为空 | 返回失败 |
| 连续多轮回绕 | 顺序保持，无越界访问 |

## 练习与验收

1. 写测试覆盖空、满、回绕、空指针和多轮读写。
2. 统计队列满的次数，并明确计数器溢出策略。
3. 画出 ISR 生产者和主循环消费者的访问时序。
4. 针对目标 MCU，写下索引原子性、编译器可见性和同步原语的依据。

**验收标准：** 普通队列逻辑测试通过；并发版本明确标注平台假设和同步方式，不把 volatile 当成完整同步方案。
